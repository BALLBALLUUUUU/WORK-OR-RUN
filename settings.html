下班倒计时

WORK OR RUN

工作时间 · 喝水提醒 · 休息提醒 · 外观与更新

工作时间

仅支持同一天内的班次，下班时间需晚于上班时间。

休息日

-

双休＝周六、周日休息；单休＝仅周日休息；未配置的周按双休处理。

勾选为休息日（周一…周日）

休息日不显示倒计时，也不会发送通知。

午休

午休期间菜单栏显示「午休中」；结束时间需晚于开始时间。

加班

工作日才计时；休息日不计入。

提醒

N 为 0–120 的整数，0 表示不提前提醒。仅在应用运行期间跨过阈值时提醒。

喝水提醒

每隔 N 分钟弹出一条系统通知提醒喝水；仅在应用运行期间触发。勾选「仅工作时间提醒」时， 只在工作日且处于上班时间内的时段提醒。

    休息提醒

    每隔 N 分钟弹出「该休息一下了 · 起身活动 X 分钟」；仅在应用运行期间触发。 勾选「仅工作时间提醒」时，只在工作日且处于上班时间内的时段提醒。

    高亮颜色

    高亮颜色会立即预览，保存后应用到保存按钮、勾选框、当前标签页、进度条与聚焦框。

    主题模式

    「跟随日出日落」按这里的日出/日落时间在浅色与深色之间切换；这些时间是可手动配置的 近似值，并非真实天文计算。其它模式立即应用。

    更新源

    格式为 owner/repo（当前默认 BALLBALLUUUUU/WORK-OR-RUN）， 否则「检测更新」会访问不到 Release。

    数据目录 -

    下班倒计时（WORK OR RUN）是一个常驻 macOS 菜单栏的小工具：显示距下班时间， 支持双休 / 单休 / 大小休 / 按月四周 / 自定义休息日、午休状态、加班计时、 喝水与休息提醒。纯本地运行；只有「检测更新」会访问 GitHub API。

    「开机启动」请在菜单栏菜单中勾选，本窗口不修改系统登录项。更新检查使用 GitHub Releases 的最新 tag 与当前版本比较。
